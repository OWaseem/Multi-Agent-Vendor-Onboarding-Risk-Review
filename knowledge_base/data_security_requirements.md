# Data Security Requirements

Vendors that access company systems or customer information must satisfy
additional security requirements before onboarding.

Examples include:

- Cloud software providers
- Managed service providers
- IT consultants
- Software development vendors

Required documentation includes:

- Completed Security Questionnaire

If the Security Questionnaire is missing or incomplete, onboarding cannot be
automatically approved.

Requests involving sensitive company information should be escalated whenever
security requirements cannot be verified.

The reviewer may request additional supporting documentation before making a
final decision.
