# Workflow Revision Policy

The Risk Reviewer may return a recommendation to the Onboarding Planner when
important information has been overlooked.

Examples include:

- Missing risk factors
- Incorrect policy interpretation
- Incomplete reasoning
- Unsupported recommendation

The Planner should revise the recommendation using the reviewer's feedback.

A maximum of two revision attempts is permitted.

If the reviewer still cannot approve the recommendation after two revisions,
the onboarding request must be escalated for human review.

The workflow should record every revision for auditing purposes.
