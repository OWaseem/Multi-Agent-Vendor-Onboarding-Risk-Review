# Vendor Onboarding Policy

All vendors must complete the standard onboarding process before they may
provide goods or services to the company.

Every new vendor request must include:

- Vendor name
- Vendor category
- Country of operation
- Requester information
- Required onboarding documents

The Intake Agent verifies that all required information has been submitted.

If required information or documents are missing, the onboarding request is
placed on hold until the requester provides the missing items.

The onboarding process may continue only after all mandatory requirements
have been satisfied.

Existing vendors may bypass certain registration steps if a valid vendor
record already exists in the vendor database.
